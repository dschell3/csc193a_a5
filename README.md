# CSC 193A – Assignment 5: Fancify My Text

A small page that styles user-entered text with JavaScript.

## Files

- `fancifymytext.html` – page with a text area and the Fancify controls
- `fancifymytext.js` – event handlers that style and transform the text

## Controls

- **Bigger!** – sets the text area font size to 24pt
- **FancyShmancy** – makes the text bold, blue, and underlined
- **BoringBetty** – resets the text to normal styling
- **Moo** – uppercases the text and appends "-Moo" to the last word of each sentence

## Running

Open `fancifymytext.html` in a browser. No build step or server needed.
